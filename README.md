# Hotel Chat AI Website

A modern, responsive website for Hotel Chat AI - an AI-powered chatbot solution for hotels.

## 🎨 Features

- **Responsive Design**: Works on all devices
- **Scattered Icon Animation**: 6 decorative icons (1.png - 6.png) positioned on the right side of the hero text
- **Video Integration**: Autoplay demo videos in tabs
- **Review Carousel**: Customer testimonials with navigation
- **Modern UI**: Clean, professional design with smooth animations

## 🚀 Getting Started

1. Open `index.html` in a web browser
2. All assets are properly organized in the `assets/` folder
3. Images, videos, and other resources load from their organized locations

## 📱 Pages

- **Homepage** (`index.html`): Main landing page with hero section and scattered icons
- **Pricing** (`pricing.html`): Pricing plans and packages
- **Demo** (`demo.html`): Interactive demo and form
- **Chatbot** (`chatbot.html`): Live chatbot demonstration
- **FAQ** (`faq.html`): Frequently asked questions
- **Legal Pages**: Privacy policy and terms of service

## 🔧 Technical Notes

- All image paths use `assets/images/` prefix
- Video files are in `assets/videos/`
- Responsive design with mobile-first approach
- SEO optimized with proper meta tags and structure
- Chatbot integration included
